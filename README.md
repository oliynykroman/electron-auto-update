# Центр оновлення Electron

Самодостатній демонстраційний проєкт механізму оновлення вебінтерфейсу Electron-застосунку. Проєкт не потребує бази даних, авторизації або API вихідної системи.

## Що демонструє проєкт

- локальний запуск Angular-інтерфейсу всередині Electron;
- завантаження інтерфейсу з віддаленого вебсервера;
- автоматичну перевірку номера вебверсії після запуску;
- ручну повторну перевірку оновлення;
- застосування нової вебверсії без перевстановлення Electron-оболонки;
- незалежні версії вебінтерфейсу й Electron-оболонки.

## Системні вимоги

Для встановлення потрібні:

- Node.js 22 LTS або Node.js 24;
- npm, який встановлюється разом із Node.js;
- macOS, Windows або Linux;
- доступ до інтернету під час першого встановлення залежностей.

Перевірити встановлені версії:

```bash
node --version
npm --version
```

Якщо команди не знайдено, встановіть Node.js із [nodejs.org](https://nodejs.org/) і перезапустіть термінал.

## Встановлення

1. Відкрийте термінал.


3. Встановіть залежності:

   ```bash
   npm install
   ```

Залежності будуть встановлені в локальний каталог `node_modules`. Глобально встановлювати Angular CLI або Electron не потрібно.

## Основний локальний запуск

Запустіть:

```bash
npm start
```

Команда автоматично:

1. створить локальну Angular-збірку;
2. встановить середовище `local` у `electron-env.json`;
3. відкриє збірку у вікні Electron.

Еквівалентна явна команда:

```bash
npm run start:local
```

Для зупинки застосунку закрийте Electron-вікно. Якщо процес залишився активним у терміналі, натисніть `Ctrl+C`.

## Запуск лише у браузері

Для перегляду Angular-інтерфейсу без Electron:

```bash
npm run start:web
```

Після компіляції відкрийте адресу:

```text
http://localhost:4200
```

У браузерному режимі Electron IPC недоступний, тому перевірка оновлення не працює. Повний механізм потрібно демонструвати через `npm start`.

## Налаштування віддаленого оновлення

Відкрийте `electron-env.json` і замініть тестові адреси власними HTTPS-адресами:

```json
{
  "environment": "production",
  "remoteUrl": "https://example.org/electron-demo/",
  "manifestUrl": "https://example.org/electron-demo/version.json"
}
```

Поля конфігурації:

- `environment` — режим запуску; віддалений інтерфейс використовується для `production`;
- `remoteUrl` — адреса каталогу з опублікованою Angular-збіркою;
- `manifestUrl` — адреса JSON-файлу з номером актуальної вебверсії.

Після налаштування запустіть:

```bash
npm run start:remote
```

Команда перемикає середовище на `production` і відкриває віддалений інтерфейс в Electron.

## Формат маніфесту оновлення

Файл `version.json` на вебсервері повинен мати такий формат:

```json
{
  "version": "1.1.0"
}
```

Номер версії повинен відповідати формату `MAJOR.MINOR.PATCH`, наприклад `1.0.0`, `1.1.0` або `2.0.3`.

## Підготовка нової вебверсії

1. Змініть номер вебверсії:

   ```bash
   node scripts/set-web-version.js 1.1.0
   ```

2. Створіть production-збірку:

   ```bash
   npx ng build --configuration production
   ```

3. Опублікуйте весь вміст каталогу `dist/electron-update-demo/` на статичному HTTPS-вебсервері за адресою, записаною в `remoteUrl`.

4. Переконайтеся, що `version.json` доступний за адресою з `manifestUrl`.

5. У запущеному Electron-застосунку натисніть «Перевірити ще раз», а після виявлення нової версії — «Застосувати оновлення».

## Запуск тестів

Тести механізму порівняння версій і перевірки URL запускаються командою:

```bash
node --test test/*.test.js
```

## Типові проблеми

### Повідомлення «Не вдалося з’єднатися із сервером оновлень»

У початковій конфігурації використовується адреса `example.invalid`. Це навмисна тестова адреса. Для перевірки віддаленого оновлення вкажіть реальний сервер в `electron-env.json`.

### У браузері написано, що інтерфейс потрібно відкрити в Electron

Це очікувана поведінка для `npm run start:web`. Запустіть повний застосунок командою `npm start`.

### Порт 4200 зайнятий

Зупиніть інший Angular-процес через `Ctrl+C` або запустіть браузерний режим на іншому порту:

```bash
npm run start:web -- --port 4300
```

## Межі механізму

Механізм оновлює Angular-вебінтерфейс. Зміни у `electron/main.js`, `electron/preload.js` або нативних залежностях потребують випуску нової Electron-оболонки.
